1️⃣  UPLOAD DOCUMENT

    • User clicks Upload

2️⃣  UPLOAD PROCESSING
    • Status bar shows: "⏳ Uploading and processing PDF..."
    • Loading spinner animates
    • Upload button becomes disabled (prevent duplicate)
    • All form buttons disabled during processing

    • Status bar shows: "✅ PDF uploaded successfully! 1 chunks (312 characters)"

4️⃣  QUESTION ENTRY
    • User types question: "What is Artificial Intelligence?"
    • Can press Enter key or click Ask button
    • Both methods trigger query

5️⃣  QUERY PROCESSING
    • Status bar shows: "⏳ Searching documents and generating answer..."
    • Loading spinner animates
    • Query input field disabled (prevent duplicate queries)
    • Ask button disabled

6️⃣  QUERY SUCCESS
    • Status bar shows: "✅ Answer generated successfully!"
    • Answer displayed: "Artificial Intelligence is a field of computer science..."

    • Answer section auto-scrolls into view
    • Query input field RE-ENABLED
    • Ask button RE-ENABLED
    • Status auto-clears after 5 seconds

7️⃣  CONTINUE CONVERSATION
    • User can type another question
    • NO need to upload document again
    • System searches all ingested documents
    • Same process repeats for next question

8️⃣  ADD SUPPLEMENTARY TEXT (Optional)
    • User can add text to existing documents
    • Add Text button processes text
    • Creates additional chunks for search
    • Queries now search PDF + added text

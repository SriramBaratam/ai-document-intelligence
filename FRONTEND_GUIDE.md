# AI Document Intelligence - Frontend User Guide

## 🎉 Frontend is Ready!

The web-based user interface for the AI Document Intelligence Platform has been successfully built and tested.

## Quick Start

### Prerequisites
- API server running on `http://localhost:8001`
- Frontend server running on `http://localhost:3000`
- Ollama running locally with Llama 3.2 3B

### Starting Both Servers

**Terminal 1 - Start Ollama:**
```bash
ollama serve
```

**Terminal 2 - Start API Server:**
```bash
cd /Users/baratamsriram/Downloads/ai-document-intelligence
source .venv/bin/activate
uvicorn app.main:app --reload --port 8001
```

**Terminal 3 - Start Frontend Server:**
```bash
cd /Users/baratamsriram/Downloads/ai-document-intelligence
python3 serve_frontend.py
```

**Terminal 4 - Open in Browser:**
```
http://localhost:3000
```

## Features

### 1. 📄 Upload PDF Documents
- **Drag and Drop:** Drag PDF files directly into the upload area
- **Click to Select:** Click the upload area to browse for files
- **Progress:** Upload status displayed with loading indicator
- **Validation:** Only PDF files are accepted
- **Automatic Processing:** PDFs are chunked, embedded, and stored in FAISS

### 2. ✍️ Add Text Directly
- **Paste Text:** Add raw text content via text area
- **Flexible Input:** Works with any text content
- **Source Tracking:** Text inputs are tracked with source identification
- **Instant Processing:** Text is immediately processed and added to the vector store

### 3. ❓ Ask Questions
- **Natural Language:** Ask any question about ingested documents
- **Context-Aware:** Answers are generated based on relevant document sections
- **Fast Retrieval:** Documents are retrieved using semantic similarity
- **AI-Powered:** Answers generated by Llama 3.2 3B

### 4. 📊 View Results
- **Answer Display:** Clear, readable AI-generated answers
- **Source Documents:** Retrieved document chunks shown with relevance scores
- **Relevance Scoring:** Semantic similarity score (0-100%) for each retrieved document
- **Document Preview:** First 100 characters of each retrieved chunk

### 5. 🔄 Status Feedback
- **Loading States:** Visual indicators during uploads and queries
- **Success Messages:** Confirmation with details (chunks created, characters processed)
- **Error Messages:** Clear error descriptions if something goes wrong
- **Auto-Clear:** Messages automatically disappear after 5 seconds

## Technical Details

### Frontend Stack
- **HTML5:** Semantic markup and accessibility
- **CSS3:** Modern styling with gradients and animations
- **Vanilla JavaScript:** No build tools required, runs directly in browser
- **Fetch API:** Handles HTTP requests to backend

### API Integration
- **Endpoints Used:**
  - `POST /ingest/pdf` - Upload PDF files
  - `POST /ingest/text` - Add text content
  - `POST /query` - Ask questions
  - `GET /health` - Check server status

### Error Handling
- Network errors display user-friendly messages
- API errors caught and displayed
- Validation of file types (PDF only)
- Input validation (no empty questions/text)

### CORS Support
- Frontend server includes CORS headers
- Allows requests from browser to API
- No authentication required for local use

## Troubleshooting

### "Cannot connect to API"
- **Solution:** Start API server on port 8001
- **Check:** `curl http://localhost:8001/health`

### "Upload failed"
- **Solution:** Ensure file is a valid PDF
- **Check:** File extension must be `.pdf`

### "No documents ingested"
- **Solution:** Upload a PDF or add text first
- **Check:** Look for success message after upload

### "Slow response time"
- **Solution:** Normal - Llama inference takes time
- **Note:** First query might be slower as models load

### Frontend server won't start
- **Solution:** Try different port (edit `serve_frontend.py`)
- **Ports 8000, 5000, 3000:** Try ports in order
